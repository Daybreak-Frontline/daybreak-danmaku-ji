弹幕点歌姬 · Windows 便携版 1.0.0

面向 B 站直播的本机点歌工具。解压后运行「弹幕点歌姬.exe」即可，压缩包不含登录数据。

使用方法：
1. 解压整个文件夹；
2. 双击「弹幕点歌姬.exe」。也可以运行 start.bat。

从旧版迁移登录和设置：
1. 先关闭旧版和新版窗口；
2. 把旧版目录里的整个 data 文件夹复制到本目录并覆盖；
3. 再启动。登录、房间号、闲时歌单会一并带过来，无需重新扫码。

点歌配置：
1. 设置 → 账号与直播：扫码登录 B 站，并登录至少一个音乐平台；
2. 填写房间号，到播放页连接弹幕；
3. 设置 → 点歌：按需配置冷却、礼物与闲时歌单。
4. 若不希望本机听到点歌声音，把输出改到直播虚拟声卡，再由直播姬采集该声卡。

捕获窗：
1. 在播放页选择样式并打开；
2. 窗口默认无边框，右键可显示边框以便拖动或关闭；
3. 直播姬 / OBS 使用「窗口捕获」选取该窗口。

桌面歌词：
1. 底部播放栏点「词」；
2. 字体、颜色、描边与透明在 设置 → 点歌 页底部。

注意：
- 压缩包不包含 data 中的登录库
- 本机升级请复制旧版 data，不要重新扫码
- 登录 Cookie 只加密存在本目录 data\
- 关闭桌面窗口即退出
- 便携包端口 54821，不要与本机测试环境 54822 同时运行
